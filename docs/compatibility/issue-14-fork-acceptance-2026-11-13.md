## 本轮仅需补测

1. 托盘彻底退出并重开 DSH，加载本次后端和客户端修复。
2. 在 B 打开上次未撤回的测试分支，发送一条消息并等待完成；保持打开，在“最近移动”找到对应 A→B 记录，点撤回。应回 A、无占用报错、输入框可用，发送消息成功，工作目录为 A，父会话完整。若找不到旧记录，重新 Fork 并迁移 A→B，再撤回。

## Desktop 必测步骤

使用两个已有测试工作区 A、B；没有时在插件中登记两个专用测试目录。以下不要使用重要会话，不要手动搬动或删除磁盘档案。

1. 在 A 新建父会话，发送“父会话验收，请只回复 P1 收到”，等待完成。用 DSH 自带 Fork/分支功能创建子会话，不是让模型调用子智能体。
2. 打开子会话，发送“分支验收，请只回复 F1 收到”，等待完成。确认能看到继承的父会话历史。**保持子会话打开，不重启**，拖到 B；确认框只选择“当前会话”，执行移动。
3. 预期立即显示在 B，不出现 `Live subagent migration is unsupported`，输入框可用。发送“请只回复 F2 收到”，应成功。询问当前有效工作目录，应为 B。父会话仍在 A，标题和历史完整。
4. 等回复完成，在插件“最近移动”中撤回这一次操作。预期子会话回 A，发送“请只回复 F3 收到”成功，工作目录为 A；父会话不受影响。
5. 再创建一个临时 Fork 并打开、发送消息，等待结束。将其归档，再从“设置 → 会话修复”删除到回收站。整个过程中不重启，预期删除成功，不出现子智能体/驻留拒绝。
6. 从回收站还原。因为删除前已归档，它应先回“已归档”列表；在那里点恢复后应即时回侧边栏。打开并发送“请只回复 F4 收到”，历史完整、正常回复。不要点“彻底删除”。
7. 从托盘彻底退出并重开。核对子会话归属与最后一次操作一致、没有重复项、父会话仍在 A；再发送一次消息。
