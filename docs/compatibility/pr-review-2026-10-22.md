## Issue #5 实现

- 驻留会话、JSONL tracker 中打开中（值为 null）或关闭中的 writer、旧 coordinator 中的句柄都阻止物理搬移。
- 未知 handle 后端或无法读取的写入状态暂停并进入队列；不把未知状态当成安全。
- 冷迁移前 flush 并重新检查。detach 后再检查，忙碌时恢复归属并保持可重试的 busy 错误码。
- 最后一次写入状态检查到 header 改写、目录移动和目标字节验证之间不让出 JavaScript 执行权，避免 await 引入的同进程写入竞态。
- 保留此前未提交的工作目录事件、投影失效、备份代际、标题和 Bundle 版本修复。
- 私有 tracker/coordinator 仅用于读取占用状态，不修改 writer/header。宿主改变内部结构时可能暂停迁移，需通过自检确认兼容性；没有承诺未知后端立即迁移。
